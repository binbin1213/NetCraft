# 家庭网络核心约束（常驻摘要）

> 本文件是 RAG/KnowledgeBase/ 的**常驻摘要**，只保留网络设计中「最易答错、且答错代价最高」的事实性约束。
> 详细步骤见同目录下的专题文档，按需加载。
> 最后核对：2025-11（版本断言见文末）

## 1. 三条设计原则

1. **光猫桥接**：光猫改为桥接模式，由主路由 PPPoE 拨号。光猫自带路由性能弱、NAT 表小，易导致连接数受限。**桥接后光猫在本局域网内没有 IP。**
2. **单一 NAT**：避免多层路由嵌套。多层 NAT 会导致端口转发困难、UPnP 失效、延迟增加。所有设备应在同一网段。
3. **有线回程**：Mesh 组网务必用网线连接节点，无线回程损耗极大。

## 2. DNS 栈端口约定（冲突高频区）

**53 端口只能被一个组件监听。** 常见组合的处理顺序：

| 组件 | 默认端口 | 与其它组件共存时 |
|---|---|---|
| AdGuard Home | 53 | 优先占用 53 |
| dnsmasq | 53 | 让位到 **5353**，继续解析内网主机名 |
| OpenClash | 53（开启 DNS 劫持后） | 与 AdGuard Home 只能二选一监听 53 |
| DoT 上游 | 853 | 不冲突 |

AdGuard Home 的 Web 向导默认在 **3000** 端口。

## 3. IP 地址规划

| 用途 | 范围 |
|---|---|
| 网络核心（路由、旁路由、防火墙） | .1 – .10 |
| 网络设施（交换机、AP 控制器） | .11 – .20 |
| 服务器 / NAS / 虚拟化 | .21 – .50 |
| DHCP 动态分配（手机、笔记本） | .100 – .200 |
| 智能家居（网关、摄像头） | .201 – .250 |

## 4. 无线（Wi-Fi）

- **2.4GHz**：只用 **1 / 6 / 11** 信道，强制 **20MHz** 频宽（40MHz 干扰过大）。
- **5GHz**：优先 **149–161**（国内高频段，干扰少）或 **36–48**；避开 DFS 信道 **52–64、100–144**（检测到雷达信号会强制断线）。
- 多 AP 组网开启 **802.11r** 快速漫游。

## 5. 常见误配（高频错误）

- 光猫未桥接却给光猫配了 LAN IP，导致双层 NAT。
- AdGuard Home 与 dnsmasq 同时监听 53，后者启动失败。
- 2.5G/10G 网卡插在千兆口上，链路成为瓶颈。
- 旁路由开启 DHCP，与主路由 DHCP 冲突。
